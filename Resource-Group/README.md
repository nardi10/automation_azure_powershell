# Resource Group

Scripts for **Resource Group** governance.

| Script | Description |
|--------|-------------|
| `Get-ResourceCountByGroup.ps1` | Counts the number of resources in each resource group and exports to CSV. |
| `Get-ResourceGroupLock.ps1` | Lists the *resource locks* (CanNotDelete / ReadOnly) of each resource group. |

> Prerequisites: **Az** module and `Connect-AzAccount`.
